# SETUP — both machines (Lenovo Windows + Mac mini)

1. Git + Node 20+ installed. Clone the repo next to `chipy-blackjack-trainer` (engine source, read-only).
2. Claude Code plugins (must match on both): superpowers, codex, playwright, figma, frontend-design,
   ui-ux-pro-max, github, design. Turn off for this repo: data (snowflake, databricks), gmail, google calendar.
3. MCP: Atlassian (read only for agents), Figma, Playwright, Ahrefs (SEO story only).
4. `npm install` then `npm run check`.
5. Windows: `git config core.autocrlf false` (the repo's .gitattributes forces LF).
