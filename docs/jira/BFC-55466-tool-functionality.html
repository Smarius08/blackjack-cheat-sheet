Introduction

This task describes what the Blackjack Cheat Sheet does when a player uses it: choosing table rules, reading the chart, tapping a cell, using Table mode, seeing what new rules change, sharing a link and printing.

The page address is https://chipy.com/tools/blackjack-cheat-sheet.

How it looks is in BFC-55465 (Tool Layout). The strategy logic, rule values, charts, cell values, notes and reference counts are in BFC-55467 (Calculation Logic & Lookup Tables). This task does not repeat them. Every move on screen and in print comes from that engine. No move is typed into the page.

Working reference: prototype/index.html in the handoff zip blackjack-cheat-sheet-handoff-2026-10-05.zip (attached to the parent task BFC-55462). It behaves as described here.

1. Defaults on load

  • Full chart view. At every screen width.
  • Rules: 4–8 decks, Dealer hits on soft 17, Double after split allowed, Surrender: any dealer card.
  • If the page address carries rules, those are used instead (section 7).
  • No count line and no changed markers on load.
  • Nothing is loaded from the network. The chart, reasons and print sheets are all built in the page. The only link that leaves the page is the Calculator link in Table mode (section 4).

2. Rule panel

  • Four controls, each a group of radio buttons shown as a segmented control: Decks (1 / 2 / 4–8), Dealer on soft 17 (Stands / Hits), Double after split (Yes / No), Surrender (Not allowed / Any dealer card / Except ace). Double down is not a control. The rule values and their meaning are in BFC-55467.
  • Choosing an option redraws the chart, the "Table rules:" sentence, the open reason panels, the Table mode result, the print sheets and the address (section 7).
  • Keyboard: Tab goes to a group, the arrow keys change the option, there is a visible focus ring.
  • Choosing the option that is already selected changes nothing.

3. Full chart and reason panel

  • Three tables: Hard hands, Soft hands (rows A,2 to A,9), Pairs. Dealer columns 2 to 10 and A. Every cell shows the move icon and the move word. No engine codes anywhere.
  • Tap, click, or press Enter or Space on a cell: a panel opens directly under that table. It shows the row label and dealer card (e.g. "Hard 16 vs dealer 10", "A,7 vs dealer 3"), the move (icon + word), the reason, and the cell's note on a separate line only when the cell has one. Reason and note text come from BFC-55467 and are never edited.
  • One panel per table. Tapping another cell in the same table replaces its content. There is no hover behaviour.
  • The CLOSE button and the Escape key close the panel. Focus goes back to the cell.
  • The page scrolls so the tapped cell and its panel are both in view. At 390 the table also scrolls sideways to the tapped column.
  • Keyboard: each table is one Tab stop (roving tabindex). Arrow keys move between cells and stop at the edges. Home and End go to the first and last dealer column.
  • If the rules change while a panel is open, the panel is redrawn for the new rules.
  • Screen readers: each cell is announced as "Hard 16 vs dealer 10: Surrender. Show why". Panels are announced politely when they open.

4. Table mode

  • Switch at the top: "Full chart | Table mode". The two options are buttons and the active one is marked. Switching hides the legend and charts and shows Table mode, and back. Print buttons stay.
  • Tap 1, your hand. Hard totals 5 to 21, Soft hands A,2 to A,9, Pairs 2,2 to 10,10 and A,A. Hard totals map to the chart rows (5, 6, 7 = row 5-7; 8 to 17 = same row; 18 to 21 = row 18-21). Soft A,2 to A,9 are chart rows 13 to 20.
  • Tap 2, dealer card. 2 to 10 and A. The dealer buttons show after the hand is picked.
  • Result. The "Recommended Play" card: hand, "Dealer shows X", the move (icon + word), the cell's note when there is one, and the link to the Calculator. The move and note are the chart's own cell for the active rules. No EV numbers and no card picking.
  • Until both taps are made the area says "Pick your hand, then the dealer’s card."
  • After tap 1 the page scrolls to the dealer buttons. After tap 2 it scrolls to the result card. Without smooth scrolling if the device asks for reduced motion.
  • In Table mode the rule panel is folded, at every width. The rules sentence stays visible. The button "Change rules" opens the panel and then reads "Hide rules".
  • If the rules change while a result is showing, the result updates at once. If its move changed, the card shows "Changed for your new rules" (text, not colour only).
  • Calculator link text: "See every move's value in the Hand Strategy Calculator". Address: https://chipy.com/tools/blackjack-calculator (the live Hand Strategy Calculator, same as in BFC-55468). The prototype already uses this address.

5. What your rules change

Details, wording rules and the reference counts are in BFC-55467 section 5. Behaviour on screen:

  • When the player changes a rule, every chart cell whose move is different from before gets the changed marker. A line shows the count with a DISMISS button.
  • Count wording: "5 moves changed for your new rules"; singular "1 move changed for your new rules"; none "No moves changed for your new rules".
  • It stays until DISMISS or the next rules change. The next change shows the difference from the previous rules. After DISMISS, focus goes to the active mode button.
  • It stays when the player switches between Full chart and Table mode.
  • Never shown: on first load, on a page opened with rules in the address, and in print.

6. Print

  • Two buttons: "Print chart" (full page) and "Print pocket card".
  • Full page: title, rules sentence, legend, Hard / Soft / Pairs tables with the word and the icon in every cell. One page, portrait, A4 and US Letter. Centred.
  • Pocket card: one landscape sheet (A4 or Letter) with two A6 panels (105 x 148 mm) side by side and a dashed fold or cut line. Left panel Hard, right panel Soft and Pairs. One letter per cell: H Hit, S Stand, D Double, P Split, R Surrender, bold and readable in black and white. Each panel has the legend and the rules sentence.
  • The chosen rules are printed on both sheets, always equal to the "Table rules:" sentence.
  • Print shows only the sheet. No rule panel, mode switch, Table mode, panels, buttons or markers.
  • The print sheets are rebuilt from the active rules every time, also just before the print dialog opens. Ctrl/Cmd+P without a button prints the full page.
  • Browser headers and footers (address, date) belong to the print dialog and are not controlled by the page.

7. My-table link

  • The rules live in the page address: https://chipy.com/tools/blackjack-cheat-sheet?decks=4-8&soft17=hits&das=yes&surrender=any (values as in BFC-55467).
  • On load the address is read before the first draw, so a shared link shows the right chart straight away.
  • Each of the four values is checked alone. A missing, empty, unknown or repeated value falls back to its default; valid ones in the same address are kept. Nothing is shown and nothing is logged.
  • On every real rules change the address is updated in place (replaceState). No new history entry, no reload. If the browser refuses (for example a local file), the chart still works.
  • Other parameters and the #hash are kept. Only the four rule keys are rewritten.
  • There is no "Copy link" button. The address bar holds the link.

Acceptance Criteria

  • On load: Full chart, 4–8 decks, hits soft 17, double after split allowed, surrender any dealer card; no count line and no markers.
  • The rule panel has the four controls with the options in section 2 and can be used with the keyboard.
  • For all 36 rule sets, every cell move and the rules sentence equal the snapshot in BFC-55467.
  • Tapping, clicking, or pressing Enter or Space on any cell opens a panel under its table with row label, dealer, move, reason, and the note on a separate line only when present. CLOSE and Escape close it and return focus to the cell.
  • Each chart table is one Tab stop. Arrow keys, Home and End move between cells without wrapping.
  • The tapped cell and its panel are in view after opening, also at 390.
  • Table mode: two taps give the Recommended Play card. For every hand x dealer card x the 36 rule sets the move and note equal the matching chart cell.
  • In Table mode the rules are folded behind "Change rules" at every width. The page scrolls to the dealer buttons after tap 1 and to the result after tap 2.
  • A rules change updates an open reason panel and a shown Table mode result at once.
  • After a rules change, changed cells are marked and the count line shows the right number and wording (N, 1, none), checked for all 216 single-field changes against BFC-55467 reference counts. DISMISS clears it. The next change replaces it.
  • No marker or count line on first load, on a link load, or in print. Table mode marks "Changed for your new rules" only when the shown move changed.
  • "Print chart" gives one portrait page and "Print pocket card" one landscape sheet, on A4 and on US Letter, each with the chosen rules, matching the snapshot. The pocket card has one letter per cell and is readable in black and white.
  • Print hides all controls, panels and markers. Ctrl/Cmd+P gives the full page.
  • A link with the four rule keys shows the right chart on load for all 36 sets. Bad values fall back per field without any message or error. A rules change rewrites only the four keys and keeps other parameters and the #hash, with no new history entry.
  • The Calculator link has the exact text in section 8, points to https://chipy.com/tools/blackjack-calculator and is at least 44 px high.
  • The page makes no network request; its only external link is the Calculator link. The engine files are byte-identical to the vendored copies.
  • The 12 checks of docs/qa/qa-run.mjs pass on the build.
